# dot-chord-centred

### The rule

In a crowded chord, balance the dot column vertically around the noteheads. See Behind Bars p. 56.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 10. Four consecutive notes in a single chord.

### Checks

1. Is the four-dot column balanced around the middle of the chord?
   Crop: measure 10, 7 spaces, 3 above, 3 below
