# dot-ledger-position

### The rule

Use the same space above an isolated ledger line for its note’s duration dot. See Behind Bars p. 55.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 3. Dotted ledger-line note.

### Checks

1. Is the dot in the space immediately above the ledger line?
   Crop: measure 3, 7 spaces, 6 above, 4 below
