### The rule

Space key-signature flats evenly so each flat clears the preceding flat without overlapping, aligning the stem of an ascending-fourth flat with the right edge of the previous flat rather than tucking them together. See Behind Bars p. 92.

### The test case

- Measure 4. Four flats (B♭, E♭, A♭, D♭) in treble clef following C major, with no cancelling naturals.
