### The rule

Start an even run of adjacent heads with the lowest head on the left and alternate regardless of stem direction. (Behind Bars p. 49)

### The test case

`single-stem-chords.musicxml` uses one high four-note run and one low four-note run.

### Checks

1. Does the down-stemmed run start on the left and alternate?
   Crop: measure 9, from 3 spaces, 7 spaces

2. Does the up-stemmed run start on the left and alternate?
   Crop: measure 9, from 11 spaces, 9 spaces
