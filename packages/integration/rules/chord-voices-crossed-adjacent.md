# chord-voices-crossed-adjacent

### The rule

When undotted adjacent voices cross, put the down-stemmed part on the left to help the heads overlap. See Behind Bars p. 54.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 30. Crossed undotted adjacent parts.

### Checks

1. Is the down-stem head to the left of the up-stem head?
   Crop: measure 30, 7 spaces, 3 above, 3 below
