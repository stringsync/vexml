### The rule

In double-stemmed writing, place accidentals before both parts (except for altered unisons) in the same order as single-stemmed chords, with the uppermost accidental closest to the notes. See Behind Bars pp. 90–91.

### The test case

`accidentals-voices.musicxml` isolates each case in its own measure.

- Measure 5. Beat 1: A♭4 (voice 1, up-stem) over E♮4 (voice 2, down-stem). Beat 3: A#4, C#5 (voice 1) over D#4, F#4 (voice 2).

### Renderers

- Behind Bars: agrees, places all accidentals before both parts with the uppermost closest
- MuseScore: agrees, places all accidentals before both parts with the uppermost closest on both beats
- Verovio: agrees, places all accidentals before both parts with the uppermost closest on both beats
- OSMD: agrees, places all accidentals before both parts with the uppermost closest on both beats
