# dot-chord-column

### The rule

In an ordinary dotted chord, give each head a dot and place the dots in one column after the heads. See Behind Bars p. 55.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 6. Spaced chord.

### Checks

1. Is there one dot per head, with all three to the right in one column?
   Crop: measure 6, from 2.5 spaces, 7 spaces, 3 above, 3 below
