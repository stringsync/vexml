# dot-crossed-chords

### The rule

In overlapping dotted chords, normally keep each dot column beside its own heads. In cramped setting both sets may follow the chords. See Behind Bars p. 58.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 21. Crossed dotted chords.

### Checks

1. Is every dot visible and clearly attributable to a chord?
   Crop: measure 21, 7 spaces, 3 above, 3 below

### Why a person decides

The book allows the columns to shift in cramped layout and gives no spacing threshold.
