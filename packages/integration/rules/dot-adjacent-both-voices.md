# dot-adjacent-both-voices

### The rule

When both adjacent parts are dotted, prefer a common column after both heads for compact layout or keep each dot near its own head. See Behind Bars pp. 56–57.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 13. Both adjacent parts dotted.
- Measure 18. Crossed adjacent parts, both dotted.

### Checks

1. Can each dot be read with its own voice?
   Crop: measure 13, 7 spaces, 3 above, 3 below
2. Do the dots remain attributable as the voices cross?
   Crop: measure 18, 7 spaces, 3 above, 3 below

### Why a person decides

The book permits a common column or individually placed dots and leaves the choice to the layout.
