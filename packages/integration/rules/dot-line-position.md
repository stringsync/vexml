# dot-line-position

### The rule

Place a line note’s dot in the space immediately above the line. See Behind Bars p. 54.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 2. Single dotted line note.

### Checks

1. Is the dot half a stave space above the head?
   Crop: measure 2, 7 spaces, 3 above, 3 below
