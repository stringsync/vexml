### The rule

Every pitched stave must begin with a clef on every system (Behind Bars p. 7). Repeating the clef at each system break keeps the player oriented when scanning from one line to the next.

### The test case

`clefs.musicxml`: a five-line stave in 4/4 whose measure 5 forces a new system (`<print new-system="yes"/>`) in bass clef.

### What to look for

A blue vertical line marks the start of system 2 (measure 5), and a box highlights the opening bass clef drawn right after it.
