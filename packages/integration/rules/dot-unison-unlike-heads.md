# dot-unison-unlike-heads

### The rule

For unlike dotted values in unison, keep a dot beside each head when space allows and use a compact placement when needed. See Behind Bars p. 59.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 26. Unlike dotted durations in unison.

### Checks

1. Does each dot read with its own duration?
   Crop: measure 26, from 2.5 spaces, 7 spaces, 3 above, 3 below

### Why a person decides

The book allows both individual and compact placement without specifying a threshold.
