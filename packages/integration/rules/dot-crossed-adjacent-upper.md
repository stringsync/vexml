# dot-crossed-adjacent-upper

### The rule

For a dotted up-stem voice crossing an adjacent undotted voice, put the dotted head first with its dot between the heads. See Behind Bars p. 57.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 19. Crossed adjacent parts, up-stem dotted.

### Checks

1. Do the dotted head, dot and undotted head appear in that order with separate horizontal extents?
   Crop: measure 19, 7 spaces, 3 above, 3 below
