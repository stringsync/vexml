# dot-duration-size

### The rule

Make duration dots larger than staccato dots so the two marks are easy to tell apart. See Behind Bars p. 54.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 1. Single dotted space note with a staccato comparison.

### Checks

1. Is the duration dot larger than the staccato dot on the same note?
   Crop: measure 1, from 6.5 spaces, 7 spaces, 3 above, 3 below
