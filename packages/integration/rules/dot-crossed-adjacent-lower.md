# dot-crossed-adjacent-lower

### The rule

For a dotted down-stem line note crossing an adjacent up-stem note, use the space above the dotted head to keep the dot clear. See Behind Bars p. 58.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 20. Crossed adjacent parts, down-stem line note dotted.

### Checks

1. Is the dot in the space above the down-stem head?
   Crop: measure 20, 7 spaces, 3 above, 3 below
