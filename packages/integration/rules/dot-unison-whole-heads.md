# dot-unison-whole-heads

### The rule

When both voices have a dotted whole note at unison, retain both heads and a separate dot for each. See Behind Bars p. 59.

### The test case

`duration-dots.musicxml` uses one attack per measure to isolate the dot placement.

- Measure 25. Two dotted whole notes in unison.

### Checks

1. Are there two separate heads with a dot for each one?
   Crop: measure 25, from 6.5 spaces, 7 spaces, 3 above, 3 below
